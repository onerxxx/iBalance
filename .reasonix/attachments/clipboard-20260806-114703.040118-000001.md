# Changelog

## 2026-07-28

### 🔝 元素高亮框与标签遮挡问题优化

#### 同类元素高亮重构为顶层 overlay 层
- 旧方案：`outline` + `::after` 标签直接作用在目标元素上，标签会被祖先 `overflow: hidden/auto` 裁剪、被祖先 stacking context（`transform`/`opacity`/`filter` 等）遮挡，且需临时改写元素的 `position`/`z-index`/`border-radius`
- 新方案：`#__so_group_hl_layer` 顶层容器（fixed + z-index 2147483645，挂 `documentElement`）+ 每个同类元素一个 `.__so_group_box` div（内含标签子元素），彻底脱离页面 stacking context 与 overflow 裁剪，零页面样式污染
- 重定位由常驻 `scroll`（capture 阶段）/ `resize` 监听驱动，rAF 节流批量执行；零尺寸或完全滚出视口的元素自动隐藏高亮框
- 移除 `GROUP_HL_ATTR` / `GROUP_HL_LABEL_ATTR` data 属性、`ensureRelativeForLabel` / `restorePosition` / `positionOverrides` 及未使用的 `SELECTED_HL_ATTR` / `SELECTED_HL_LABEL_ATTR` / `HOVER_HL_ATTR` 常量

#### 标签视口自适应（选中 overlay 与同类高亮层共用）
- 新增 `fitLabelToViewport`：元素下方空间不足（且上方更宽裕）时标签翻转到元素上方（`__so_label_above`），溢出左视口时改为左对齐（`__so_label_left`），解决标签被视口边缘裁掉的问题
- 选中 overlay 每次重定位时调用；`updateSelectedLabel` 更新文本后也重新适配一次

#### 高亮框不再遮挡面板
- 所有高亮 overlay z-index 整体下移一级（选中 2147483646、悬停 2147483645、同类层 2147483644、加载 2147483643），确保始终低于面板 / 编辑弹窗（2147483647）

## 2026-07-25

### ✏️ 代码编辑器迁移至 CodeJar

#### 弃用 textarea+pre 双层叠层结构
- 设置页代码卡片与编辑弹窗统一改用 CodeJar 单层 `contenteditable` 编辑器
- 高亮回调直接操作同一 DOM 的 `innerHTML`（`highlightCSS(escapeHtml(textContent))`），光标与文字渲染天然对齐
- 移除 `syncEditorHl` / `autoResizeEditorHl` 等双层同步逻辑
- 新增 `libs/codejar.js`（v4.3.0 改造版，挂载到 `window.SR.CodeJar`），manifest content_scripts 第二组在 `shared.js` 与 `content.js` 之间加载

#### CodeJar 配置
- `tab: '  '`（2 空格缩进）
- `indentOn: /[({[]$/`（行尾是 `{ ( [` 时新行自动缩进）
- `addClosing: true`（自动闭合括号）
- `history: true`（启用撤销/重做）
- `onUpdate` → `scheduleEditorSave`（400ms 防抖）→ `flushEditorSave` 实时落盘并同步已注入 `<style>`

### 🪟 页面内编辑弹窗（so-editor）

#### 弹窗实现
- 在当前网页 Shadow DOM 内独立于浮动面板渲染，结构与设置页 `.saved-list__item` 严格一致
- 默认生成在页面右上角，`.item-head` 整行可拖动（避开右侧按钮），松开保留位置；再次 `openEditor` 重置回右上角
- 卡片头部新增「跳转设置页」与「关闭」两个内联 SVG 按钮
- 跳转通过 background 中转 `OPEN_SETTINGS` 消息（content script 无 `chrome.tabs` 权限），URL hash `saved:domain` 直达对应域名分组

#### `OPEN_EDITOR` 消息分流
- popup 编辑按钮 → `OPEN_EDITOR {id}` → content.js
- content.js 读 `syncStore.get(DEFAULTS)`：
  - `editMode === 'settings'` → 发 `OPEN_SETTINGS` 跳设置页
  - 否则（默认 `popup`）→ `openEditor(id)` 弹卡片

### 🐛 修复记录

1. **光标位置错位**：textarea（font-weight 400）与 pre（500）字重差异导致单行 `pre` + `wrap='off'` 模式下字符宽度累计偏移。改用 CodeJar 单层结构后根因消失。
2. **代码末尾空白**：textarea `min-height` 在短内容时撑出视觉空白；改用 CodeJar 后由内容驱动高度。
3. **行内右侧空白**：`white-space: pre-wrap` + `word-break: break-all` 在 380px 窄容器内换行不一致；统一为 `pre` + 横向滚动后由 CodeJar 接管渲染。
4. **跳转设置页按钮失效**：原直接调 `chrome.tabs` 失败（content script 无权限），改为通过 background 中转 `OPEN_SETTINGS`。
5. **`autoResizeTextarea` 在设置页未生效**：max-height 未从 400px 同步更新为 300px；改用 CodeJar 后由 `max-height` 直接约束。
6. **设置页代码框聚焦失效**：从 popup 编辑按钮跳转 `settings.html#saved:domain|id` 后未聚焦到对应卡片代码框。两个 `DOMContentLoaded` 监听器都调用 `renderSaved()`，第二个重建 DOM（`wrap.innerHTML=''`）打断第一个 `await renderSaved()` 后调度的 `requestAnimationFrame(focus)`。新增 `savedRenderedByHash` 标志位：第一个 DOMContentLoaded 渲染后置 `true`，第二个据此跳过重复渲染；同时删除 `renderSaved` 内部的 focus 逻辑，focus 仅在第一个 DOMContentLoaded 的 `await renderSaved()` 之后执行一次。
7. **关闭代码弹窗后元素高亮框残留**：从 popup hover 条目触发 `HOVER_PREVIEW`（`showHighlight` 复用 `selectedHlOverlayEl`）后点"编辑"打开弹窗，关闭弹窗时高亮框未消失。`closeEditor()` 原只清理 saveTimer 与 class，漏清高亮。补调 `hideSelectedHighlight()`（与 `hidePanel` 复用同一清理函数：`hideHighlight` + `clearGroupHighlight` + `hideLoadingOverlay` + 清 `selectedHighlightEl`）。
8. **点编辑按钮后撤销预览状态残留**：popup hover 条目进入"撤销预览"（content.js `removeCss` 临时移除注入 + 高亮），点"编辑"后 `window.close()` 销毁 popup，`mouseleave` 丢失导致 `HOVER_PREVIEW enter:false` 未发送，注入未恢复、编辑期间页面看不到该条目样式。编辑按钮 click handler 改为主动退出 hover 预览：清 debounce timer、判断 `hover-ready`、`await` 发 `enter:false` 恢复注入 + 清高亮，再发 `OPEN_EDITOR`。`wasPreviewing` 判断精确覆盖 debounce 200ms 内/外两种时序。
